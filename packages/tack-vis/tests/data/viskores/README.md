# Viskores test meshes

Copies of files from Viskores' `data/data/unstructured/` (Viskores
`ab6b17965`), used by `test_viskores_datasets.py` for the cases Viskores'
`UnitTestContourFilter` runs on them. They are Viskores', under its license in
`LICENSE-Viskores.txt`.

| File | Bytes | What it holds |
|---|---|---|
| `mixed-cell-shapes.vtk` | 1126 | one cell of every VTK type, with a point and a cell array both named `scalars` |
| `wedge_cells.vtk` | 4045 | wedges with a gyroid field |
