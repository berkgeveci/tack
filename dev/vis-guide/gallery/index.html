    Gallery¶

    What the cutting filters make of each kind of cell. Every picture is a script in docs/gallery/ that builds its data, runs Tack's filter, and draws the result through VTK: Tack makes everything drawn -- the result's polygons, their normals (surface_normals(..., weights="area")), and the outline, each cell edge as lines (extract_edges(..., subdivision=12), which follows a curved geometry) -- and VTK only draws linear polygons and lines. Run one alone (uv run python docs/gallery/contour.py curved --arch metal), or all of them with docs/gallery/build.py.

    The kinds of cells, left to right:

    • Polyhedra: Voronoi cells of random points extruded through the cube, a polyhedral topology whose faces have up to a dozen points; the field is point data, linear on each cell's sub-tetrahedra.
    • Tetrahedra: the cube's 8 x 8 x 8 hexahedra cut into tetrahedra, the field linear in each.
    • Order 4 on straight cells: 27 hexahedra, the field H1 of order 4. The cuts curve inside the cells: they are cut on linear sub-cells, 6 a side, with each crossing placed on the field itself.
    • Order 3 on curved cells: the same 27 hexahedra twisted and bowed by an order-3 geometry, the field H1 of order 3 on it.

    Each cuts the same field, Schwarz's P surface: cos 2πx + cos 2πy + cos 2πz.

    The datasets 
    def dataset(kind):
    """The dataset of ``kind`` (``KINDS``), with the field ``u`` (``schwarz``)."""
    if kind == "polyhedra":
        data = _voronoi_columns()
        data.fields["u"] = td.interpolate(data, schwarz, td.H1(data))
    elif kind == "linear":
        grid = td.uniform_grid((9, 9, 9), spacing=(1 / 8,) * 3)
        data = td.tetrahedralize(grid)
        data.fields["u"] = td.interpolate(data, schwarz, td.H1(data))
    elif kind == "high-order":
        # Few cells, a field of order 4: its surfaces curve inside the cells.
        grid = td.uniform_grid((4, 4, 4), spacing=(1 / 3,) * 3)
        data = td.extract_cells(grid, np.arange(grid.num_cells))
        data.fields["u"] = td.interpolate(data, schwarz, td.H1(data, order=4))
    elif kind == "curved":
        grid = td.uniform_grid((4, 4, 4), spacing=(1 / 3,) * 3)
        data = td.extract_cells(grid, np.arange(grid.num_cells))
        data.geometry = td.interpolate(data, _twist, td.H1(data, order=3), dtype=tack.vec3())
        data.fields["u"] = td.interpolate(data, schwarz, td.H1(data, order=3))
    else:
        raise ValueError(f"no dataset of kind {kind!r}")
    return data

    Clip¶

    A ball about the cube's near top corner taken out, the kept part's surface colored by the field. Polyhedra are clipped cell by cell into polyhedra; on the high-order and curved cells, the cells wholly kept stay whole and only the cut ones are cut on sub-cells. An implicit function is cut as the geometry carries it: on the 27 straight hexahedra the ball is trilinear in each cell, a coarse ball, while on the order-3 curved cells it is cubic, round to the eye. The boundaries are shaded flat, since a clipped solid has sharp edges.

    • Tetrahedra

    • Order 4 on straight cells
