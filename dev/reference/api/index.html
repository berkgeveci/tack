    Devices¶

    A kernel runs on its arrays' device: the default device when that can address them, otherwise theirs. See Backends: Devices.

    tack.device ¶

    device(spec='cpu', **options) -> Device

    The device spec names: "cpu", "metal", "cuda", "cuda:0", "hip", "level_zero"; a Device is returned as it is.

    Without options it is made on first use and the same device afterwards, so its compiled kernels and arrays are shared by everything that asks. Options go to the backend and must be ones it declares in Backend.device_options; they make a new device each call. The CPU takes num_threads; Level Zero takes external_context, the driver, device and context handles of a context owned by another library, so both can address the same memory.

    "cuda:N" is device N as the runtime numbers it (CUDA's ordinal, HIP's device id, the index among the first Level Zero driver's devices); device_count says how many there are. A bare "cuda" or "hip" is the device the calling thread already uses: the one of a CUDA context another library made current, HIP's current device, else device 0. "level_zero" is device 0.

    with tack.device("cuda"): makes it the default device in the block.

    def device(spec="cpu", **options) -> Device:
    """The device ``spec`` names: ``"cpu"``, ``"metal"``, ``"cuda"``, ``"cuda:0"``,
    ``"hip"``, ``"level_zero"``; a `Device` is returned as it is.

    Without options it is made on first use and the same device afterwards,
    so its compiled kernels and arrays are shared by everything that asks.
    Options go to the backend and must be ones it declares in
    `Backend.device_options`; they make a new device each call. The CPU
    takes ``num_threads``; Level Zero takes ``external_context``, the
    driver, device and context handles of a context owned by another
    library, so both can address the same memory.

    ``"cuda:N"`` is device N as the runtime numbers it (CUDA's ordinal,
    HIP's device id, the index among the first Level Zero driver's
    devices); `device_count` says how many there are. A bare ``"cuda"`` or
    ``"hip"`` is the device the calling thread already uses: the one of a
    CUDA context another library made current, HIP's current device, else
    device 0. ``"level_zero"`` is device 0.

    ``with tack.device("cuda"):`` makes it the default device in the block.
    """
    if isinstance(spec, Device):
        if options:
            raise TypeError("options make a new device: pass a device spec, not a Device")
        return spec
    kind, index = _parse(spec)
    if options:
        return as_device(_construct(kind, options, index))
    if index is None:
        index = _current_index(kind)
    with _lock:
        found = _devices.get((kind, index))
        if found is None:
            found = _devices[(kind, index)] = _construct(kind, {}, index)
        return as_device(found)

    def device_count(kind: str) -> int:
    """How many devices of type ``kind`` this machine has: 0 where it cannot start.

    Counting makes no device: ``tack.device(f"cuda:{n}")`` for ``n`` below

    def set_default_device(spec="cpu", **options) -> Device:
    """Make ``spec``'s device the default: where arrays are allocated, and where
    kernels without arrays run. Returns it.

    The device is ``tack.device(spec, **options)``: without options the same

    Arrays¶

    tack.Array holds storage on one device (a.device), chosen at allocation. Its shape counts elements; its dtype describes one scalar, vector or matrix element. tack.dataset.Field instead couples coefficient values with a space on a topology. See Arrays and Types for examples.

    tack.Array ¶

    Array(
    dtype: ScalarType,
    shape: tuple[int, ...],
    buffer: DeviceBuffer,
    writable: bool = True,
    device=None,
)

    An n-dimensional array of scalar, vector or matrix elements on a device.

    shape counts elements and dtype describes one element, so an array of shape (n,) and dtype vec3(f32) holds 3 * n scalars and downloads as (n, 3).

    layout says how a vector or matrix array stores its components: "aos" (the default) interleaves them in one buffer, "soa" keeps one scalar array per component (SoaArray). An array of scalars says "aos".

    def to_device(self, device) -> 'Array':
    """This array on ``device`` (a `tack.Device` or a spec such as ``"cpu"``):
    itself if its memory is already usable there, else a copy."""
    from tack.runtime.dispatch import backend_of
    target = backend_of(device)

        return self
    return array(self.numpy(), self.dtype, device=target)

    def __getitem__(self, index):
    """Read one element from the host: ``a[i]``, ``a[i, j]``, or ``a[()]`` for a
    zero-dimensional array.

    An array of scalars gives a Python number; a vector or matrix array
    gives a NumPy array of the element. Negative indices count from
    the end, as in Python. This is for inspection and for host-side
    decisions: on backends without host-visible memory each read is a

    ``numpy()``. Arrays are not written this way; see ``tack.copyto``
    and ``fill``.

            isinstance(i, (int, np.integer)) and not isinstance(i, bool) for i in indices):

    def array(obj, dtype=None, *, device=None, layout=None) -> Array:
    """A new array holding a copy of ``obj``: a NumPy array, a sequence or a Tack array.

    Without ``dtype``, all of ``obj``'s dimensions are array dimensions, a
    NumPy array keeps its dtype, and Python floats and ints become f32 and
    i32 (i64 if a value needs it). With an element dtype such as
    ``vec3(f32)``, the trailing dimensions are the elements' components.
    A Tack array is copied on its device unless ``device`` names another.
    ``layout`` is ``"aos"`` or ``"soa"`` for a vector or matrix array (see
    `SoaArray`); by default a Tack array keeps its own and other data is
    interleaved.
    """

        if layout is not None and layout != obj.layout:
            if device is not None:
                obj = obj.to_device(device)
            out = empty(obj.shape, obj.dtype if dtype is None else dtype,
                        device=obj._backend, layout=layout)
            copyto(out, obj)
            return out
        if device is not None and _target(device).memory_domain != obj._backend.memory_domain:
            moved = obj.to_device(device)
            return moved if dtype is None else moved.astype(dtype)
        return obj.copy() if dtype is None else obj.astype(dtype)
    host = np.asarray(obj)
    dtype = _host_dtype(host, obj) if dtype is None else as_dtype(dtype)
    shape = host.shape

        if len(shape) < rank or shape[-rank:] != dtype.shape:
            raise ValueError(f"input shape {shape} must end with element shape {dtype.shape}")

    out._upload(host.astype(out.scalar_dtype.numpy_dtype, copy=False))
    return out

    def copyto(dst: Array, src):
    """Copy ``src`` into the existing array ``dst``, as ``np.copyto`` does.

    ``src`` is host data -- a NumPy array, a sequence or a scalar -- whose
    shape is ``dst.numpy()``'s or broadcasts to it, converted to ``dst``'s
    dtype; or a Tack array of ``dst``'s shape on ``dst``'s device, copied
    there (``src.to_device(dst.device)`` brings one from another device).

    It only writes into Tack arrays. `numpy` reads one into a new NumPy
    array; ``np.copyto`` copies between NumPy arrays.
    """
    if not isinstance(dst, Array):
        raise TypeError(f"copyto() writes into a Tack array, not {type(dst).__name__}")
    if isinstance(src, Array):
        if src.shape != dst.shape or src.scalar_size != dst.scalar_size:
            raise ValueError(f"copyto() from an array of shape {src.shape} and dtype "
                             f"{src.dtype} into one of shape {dst.shape} and dtype {dst.dtype}")
        from tack.runtime.dispatch import same_device
        same_device("copyto()", (dst, src))
        dst._check_writable()
        from tack.algorithms.copy import copy as _copy
        if src.layout == dst.layout == "aos":
            _copy(src._scalar_view(), dst._scalar_view(), dst.scalar_size)
            return
        # An SOA array has no one buffer: copy element by element, which
        # reads and writes either layout.
        if getattr(src.dtype, 'shape', None) != getattr(dst.dtype, 'shape', None):
            raise ValueError(f"copyto() from an array of {src.dtype} elements into one "
                             f"of {dst.dtype} elements")
        _copy(src.reshape(src.size), dst.reshape(dst.size), dst.size)
        return
    host = np.asarray(src, dtype=dst.scalar_dtype.numpy_dtype)
    expected = dst._host_shape
    if host.shape != expected:
        try:
            host = np.broadcast_to(host, expected)
        except ValueError:
            raise ValueError(f"copyto() into an array whose values have shape {expected}: "
                             f"cannot broadcast shape {host.shape}") from None
    dst._upload(host)

    """Wrap existing device memory as a Tack array without copying.

    Use this for interop with external libraries (pycuda, cupy, Catalyst)

        ptr: device pointer (integer) or backend-specific buffer object.
             - CPU: integer address or numpy array
             - Metal: MTLBuffer object (from PyObjC)
             - CUDA/HIP: device pointer as integer
             - Level Zero: device pointer as integer

        dtype: scalar or element type (tack.f32, tack.vec3(), np.int32, ...)
        device: the device whose memory this is; by default the default device
        writable: if False (default), copyto() and fill() raise errors

    Returns:
        An Array wrapping the external memory.
    """

    shape = _array_shape(shape)
    dtype = as_dtype(dtype)
    if isinstance(dtype, ElementType):
        scalar = dtype.scalar_dtype
        storage = (int(math.prod(shape)) * dtype.size,)
    else:
        scalar, storage = dtype, shape
    backend = _target(device)

    # Validate the pointer's memory space against what this backend expects,
    # on backends that distinguish device memory; Metal MTLBuffer objects
    # and CPU numpy arrays are not addresses and need no check. Any form a
    # device pointer arrives in -- int, numpy integer, CUdeviceptr -- is
    # checked, not only a Python int.
    if backend.device_memory_spaces:

            raise TypeError(
                f"array_from_ptr() on the {backend.label} backend takes a "
                f"device address (an integer, or an object int() accepts), "
                f"not {type(ptr).__name__}.")

        if space not in backend.device_memory_spaces:
            raise ValueError(
                f"Pointer is in '{space}' memory but the device is "
                f"'{backend.label}'. array_from_ptr() requires a device "
                f"pointer. Use tack.array() to copy host data to the device.")

    buf = backend.wrap_ptr(ptr, scalar, storage)
    return _array_view(dtype, shape, buf, writable=writable, device=backend)

    def array_to_dlpack(array, versioned=False):
    """Create a DLPack capsule from a Tack array.

    With `versioned`, produces a v1.0 DLManagedTensorVersioned in a
    'dltensor_versioned' capsule; otherwise the legacy DLManagedTensor in
    a 'dltensor' one. Only the versioned form can carry the read-only
    flag, so a non-writable array exported the legacy way arrives as
    writable -- the legacy protocol simply has no way to say otherwise.
    """
    device_type, device_id, data_ptr = _get_device_info(array)

    dl_dtype = _DTYPE_TO_DLPACK.get(array.scalar_dtype)
    if dl_dtype is None:
        raise TypeError(f"DLPack does not support dtype: {array.dtype}")
    code, bits, lanes = dl_dtype

    shape = array._host_shape
    ndim = len(shape)
    shape_arr = (ctypes.c_int64 * ndim)(*shape)

    # Contiguous C-order strides (in elements, not bytes)
    strides_arr = (ctypes.c_int64 * ndim)()
    stride = 1
    for i in range(ndim - 1, -1, -1):
        strides_arr[i] = stride
        stride *= shape[i]

    if versioned:
        managed = DLManagedTensorVersioned()
        managed.version = DLPackVersion(major=1, minor=0)
        managed.flags = 0 if array._writable else DLPACK_FLAG_BITMASK_READ_ONLY
        capsule_name = b"dltensor_versioned"
        deleter = _dlpack_deleter_versioned
    else:
        managed = DLManagedTensor()
        capsule_name = b"dltensor"
        deleter = _dlpack_deleter

    managed.dl_tensor.data = ctypes.c_void_p(data_ptr)
    managed.dl_tensor.device = DLDevice(device_type=device_type, device_id=device_id)
    managed.dl_tensor.ndim = ndim
    managed.dl_tensor.dtype = DLDataType(code=code, bits=bits, lanes=lanes)
    managed.dl_tensor.shape = shape_arr
    managed.dl_tensor.strides = strides_arr
    managed.dl_tensor.byte_offset = 0

    # The key travels in manager_ctx, which is the only thing the deleter
    # gets back. Pin everything the capsule points at under that key.
    key = next(_ctx_keys)
    managed.manager_ctx = ctypes.c_void_p(key)
    managed.deleter = deleter
    _prevent_gc[key] = (array, managed, shape_arr, strides_arr)

    # addressof, not byref: byref yields a temporary whose lifetime is not
    # tied to the capsule. `managed` itself is kept alive by _prevent_gc.
    return _PyCapsule_New(
        ctypes.addressof(managed), capsule_name,
        ctypes.cast(_capsule_destructor, ctypes.c_void_p),
    )

    def dlpack_to_array(source, writable=True, device=None):
    """Wrap a DLPack tensor as a Tack array, without copying.

    `source` may be a capsule or anything implementing ``__dlpack__`` -- a
    CuPy array, a PyTorch tensor, a VTK array via
    ``vtkmodules.util.dlpack_support``.

    The tensor is held for as long as the array lives, so the source may be
    dropped immediately. The array does not copy, so the two share memory
    and a write through either is visible to the other.

    ``device`` is where the array goes. By default it is the default
    device when that can wrap the tensor, else the tensor's own device, as
    the array API's ``from_dlpack`` keeps an array on its device: CUDA
    memory imported with the CPU as default is a CUDA array, not a copy.

    Raises RuntimeError if ``device`` is given and cannot wrap the tensor --
    CUDA memory imported onto the CPU device. Metal refuses host tensors for
    a different reason, and says which: it can read that memory, it just
    cannot make an MTLBuffer out of it.
    """
    from tack.lang.array import _target, array_from_ptr
    from tack.runtime.dispatch import get_backend

    capsule = _request_capsule(source)

    capsule_ptr = ctypes.cast(id(capsule), ctypes.c_void_p)
    if _PyCapsule_IsValid(capsule_ptr, b"dltensor_versioned"):
        name, used_name = b"dltensor_versioned", b"used_dltensor_versioned"
        struct = DLManagedTensorVersioned
    elif _PyCapsule_IsValid(capsule_ptr, b"dltensor"):
        name, used_name = b"dltensor", b"used_dltensor"
        struct = DLManagedTensor
    else:
        raise ValueError(
            "expected an unconsumed DLPack capsule; this one has already "
            "been taken by another consumer")

    managed_ptr = _PyCapsule_GetPointer(capsule_ptr, name)
    managed = ctypes.cast(managed_ptr, ctypes.POINTER(struct)).contents
    tensor = managed.dl_tensor

    if struct is DLManagedTensorVersioned and \
            managed.flags & DLPACK_FLAG_BITMASK_READ_ONLY:
        # The producer says this memory must not be written. Honour it rather
        # than handing back an array whose writes go somewhere unexpected.
        writable = False

    if not tensor.data:
        raise ValueError("the tensor has a null data pointer")

    dtype = _DLPACK_TO_DTYPE.get((tensor.dtype.code, tensor.dtype.bits))
    if dtype is None:
        raise TypeError(
            f"no Tack dtype for DLPack (code={tensor.dtype.code}, "
            f"bits={tensor.dtype.bits})")
    if tensor.dtype.lanes != 1:
        raise TypeError(
            f"vectorized DLPack dtypes are not supported (lanes={tensor.dtype.lanes})")

    shape = tuple(tensor.shape[i] for i in range(tensor.ndim))

    # Only C-contiguous tensors can be wrapped. Anything else would be read
    # with the wrong stride, which produces plausible-looking wrong numbers.
    if tensor.strides:
        expected, stride = [0] * tensor.ndim, 1
        for i in range(tensor.ndim - 1, -1, -1):
            expected[i] = stride
            stride *= shape[i]
        actual = [tensor.strides[i] for i in range(tensor.ndim)]
        if actual != expected:
            raise ValueError(
                f"only C-contiguous tensors can be wrapped without copying; "
                f"strides {tuple(actual)} != {tuple(expected)}")

    allowed = _DEVICE_BACKENDS.get(tensor.device.device_type)
    if tensor.device.device_type == kDLMetal:
        raise ValueError(
            "Metal DLPack tensors (kDLMetal) cannot be imported: Tack has "
            "no way yet to wrap the MTLBuffer handle they carry. Move the "
            "tensor to host memory in the producing library, then import "
            "it with copy=True.")
    if allowed is None:
        raise ValueError(
            f"unsupported DLPack device type {tensor.device.device_type}")
    if device is not None:
        backend = _target(device)
    else:
        backend = get_backend()
        if backend.name not in allowed or (
                backend.multi_device and backend.ordinal != tensor.device.device_id):
            backend = _tensor_device(allowed[0], tensor.device.device_id)
    if backend.name not in allowed:
        message = (
            f"the tensor is on a device the '{backend.name}' device cannot "
            f"wrap without copying (DLPack device type "
            f"{tensor.device.device_type}). Import it on its own device with "
            f"tack.from_dlpack(x, device='{allowed[0]}'), or pass copy=True.")
        if backend.dlpack_refusal_note:
            message += f" {backend.dlpack_refusal_note}"
        raise RuntimeError(message)

    array = array_from_ptr(
        (tensor.data or 0) + tensor.byte_offset, shape, dtype, device=backend,
        writable=writable)

    # Adopt the capsule: rename it so nobody else releases it, and attach the
    # hold to the array so the producer is told when the array is gone.
    _PyCapsule_SetName(capsule, used_name)
    array._dlpack_hold = _CapsuleHold(capsule, managed_ptr, struct)
    return array

    Random numbers¶

    tack.random ¶

    Random numbers in kernels, from a counter-based generator with explicit state.

    Nothing here is hidden: a kernel seeds a u32 state from the element it works on and a stream number, and every draw returns the value and the next state. The sequence is a pure function of those integers, so the same program draws the same numbers on every backend and for any thread order, and a NumPy reference that calls the np_ mirrors below draws exactly the same ones::

    from tack import random

@tack.kernel
def scatter(pos, n, frame):
    for i in range(n):
        state = random.seed(i, frame)        # element i of this frame
        u, state = random.uniform(state)     # f32 in [0, 1)
        z, state = random.normal(state)      # standard normal
        d, state = random.direction3(state)  # a unit 3-vector
        pos[i] = [u, z, d.x]

    The generator is PCG's output permutation (RXS-M-XS on 32 bits) over a linear congruential step, in wrapping u32 arithmetic. uniform is the state's top 24 bits scaled, so it is exact and identical everywhere; normal and the directions go through log, sqrt, cos and sin, so they agree across backends to those functions' rounding. Taichi's ti.random() keeps hidden per-thread state instead; its results depend on the thread schedule and cannot be reproduced by a reference.

        return perm  # every key is equal: the identity is the stable order

    mapped_b = tack.empty((n,), tack.u64)
    perm_b = tack.empty((n,), indices)
    if get_backend().supports_workgroups:
        # Tiles sorted into the second buffers, then scattered back: the
        # pass's result is where its input was.
        ntiles = (n + _TILE - 1) // _TILE
        counts = tack.empty((_RADIX * ntiles,), tack.i32)
        offsets = tack.empty((_RADIX * ntiles,), indices)
        starts = tack.empty((_RADIX * ntiles,), tack.i32)
        for p in range(passes):
            shift = p * _RADIX_BITS
            _sort_tiles(mapped, perm, mapped_b, perm_b, counts, starts, base, shift, n,
                        ntiles)
            exclusive_scan(counts, offsets, _RADIX * ntiles, total=False)
            _scatter_tiles(mapped_b, perm_b, mapped, perm, offsets, starts, base, shift, n,
                           ntiles)
        return perm
    nchunks = (n + _CHUNK - 1) // _CHUNK
    counts = tack.empty((_RADIX * nchunks,), tack.i32)
    offsets = tack.empty((_RADIX * nchunks,), indices)
    src_keys, src_perm, dst_keys, dst_perm = mapped, perm, mapped_b, perm_b
    for p in range(passes):
        shift = p * _RADIX_BITS
        _count_digits(src_keys, counts, base, shift, n, _CHUNK, nchunks)
        exclusive_scan(counts, offsets, _RADIX * nchunks, total=False)
        _scatter_digits(src_keys, src_perm, dst_keys, dst_perm, offsets,
                        base, shift, n, _CHUNK, nchunks)
        src_keys, dst_keys = dst_keys, src_keys
        src_perm, dst_perm = dst_perm, src_perm
    if src_perm is not perm:
        copy(src_perm, perm, n)
    return perm
